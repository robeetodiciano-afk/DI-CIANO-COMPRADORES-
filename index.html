Ficha técnica y reglamentación

Para cada ingrediente, la ficha comercial explica una posible función. Los datos normativos específicos se muestran únicamente cuando existe una referencia concreta. No se exhiben dosis genéricas ni se presenta el catálogo como certificación de aptitud universal.
